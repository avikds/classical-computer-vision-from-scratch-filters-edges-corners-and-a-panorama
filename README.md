# classical-computer-vision-from-scratch-filters-edges-corners-and-a-panorama
Build the classical image-stitching pipeline in plain NumPy, one piece at a time, and use it to turn two overlapping photographs into a single panorama. A seeded generator renders the photographs from a flat world of layered shapes, so you always know the true homography and the true scene. That lets you measure every stage instead of judging it…
